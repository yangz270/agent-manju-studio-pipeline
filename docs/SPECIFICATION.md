## 1. 2026 核心代际演进与底层参数铁律

本手册深度吸收 5 份 2026 核心知识库语料（模块 00~04），彻底剔除旧版 SD 1.5 时代的过时经验误导：

### 1.1 新旧架构断代式对比与避坑指南
1. **模型加载方式变异**：
   * 旧世代：单一 `Checkpoint 加载器` 吐出 MODEL/CLIP/VAE。
   * **2026 新世代**：**三件套解耦加载**：`UNET 加载器` (diffusion_models) + `CLIP 加载器` (text_encoders, Qwen3-VL/Lumina/C2) + `VAE 加载器` (vae)。视频流更必须配备 **video VAE + audio VAE** 双路编解码。
2. **引导系数（CFG）铁律**：
   * **模型越强，CFG 必须越低！**
   * SD 1.5 时代用 6.5~8.0；**2026 新模型（Turbo / DiT / Wan 2.2 / Krea2 / H3 / Boogu）严格锁死为 1**！在 2026 新模型上把 CFG 拉到 7 会导致极度过拟合（死黑死白、锐化刺眼、色彩爆炸变抽象画）。
3. **采样步数（Steps）铁律**：
   * 2026 加速蒸馏模型通常仅需 **4~12 步**（Boogu 4步、Z-Image 8~9步、Krea2 8~10步、H3 12步）；盲目跑 20~30 步不仅浪费数倍算力，还极易引发过曝与结构畸变。唯独 Qwen-Image 2.1 未挂加速 LoRA 时需 25~40 步慢跑保质。
4. **负面提示词（Negative Prompt）机制变异**：
   * 2026 新模型全面弱化负向词，直接接入 **`Conditioning Zero Out（条件零化）`** 节点占位，强行堆砌旧版负面词无正向收益。
5. **音视频防野生 BGM 铁律**：
   * 多模态音画模型（H3 / LTX 2.3）提示词末尾必须写死：`“禁止出现背景音乐，不出现字幕与文字”`（英文：`No background music, no BGM, no subtitles, no text overlays, clean audio.`），防止模型脑补野生配乐污染台词音轨。

## 4. 第三代角色资产与 16:9 横屏分镜标准 SOP

### 4.1 角色资产建立第三代 SOP（Krea2 + Qwen 2.1 组合拳）
1. **Step 1（Krea2 定风格出立绘）**：
   * 严格遵循“纯白背景、全身正面站立含鞋、直视镜头、删掉动作动词”，生成高精度单人立绘；
2. **Step 2（Qwen-Image 2.1 合成资产图）**：
   * 将立绘与四宫格白膜模板同时喂入 Qwen 2.1，生成 **4:3 横版三视图** 或 **2×2 四宫格**（**铁律：必须裁掉右下角全身图的小脸，强迫模型只参考大图五官，彻底杜绝视频侧脸崩坏！**）。
3. **输入尺寸上限护栏**：
   * 喂入 `C2 Edit` 节点前，必须严格将图像最长边缩放限制在 1600px（总像素 <= 200 万），防止报 OOM 崩溃。

### 4.2 16:9 影视横屏构图与细节控制
* **基准尺寸**：`768×432`（单镜）/ `1536×864`（四宫格 2x2），严格保证 8 像素对齐。
* **横屏安全区**：
  ```text
  cinematic widescreen 16:9 composition, horizontal rule of thirds framing, balanced lateral margins, theatrical breathing headroom, space reserved for bottom subtitles
  ```
* **LOD 景别动态过滤**：特写剔除鞋履防假肢，全景恢复全身比例与草鞋，弱化面部微观词防崩脸。
* **物理色温一体化**：全景特写均绑定古风主场景(Main_Scene) `6500K 漫射冷光 + 3200K 边缘轮廓光`，杜绝贴纸抠图感。
* **多人同框站位铁律**：严禁在提示词中写角色名字，必须使用“从左到右图一、图二、图三”定位具体位置与动作，杜绝人脸混淆。

## 5. 视频生成与剪映总装核心技术 (Agent 8 & 9)

### 5.1 镜头动效三级智能路由与 FlashVSR 1.1 1080P 超分 (Agent 8)
1. **三级动效智能分流**：
   * **Tier A（特写台词）**：自动分流至 LivePortrait / 口型微表情驱动（音频驱动下颌开合 + 2.5s 生理性眨眼 + 头部微呼吸）；
   * **Tier B（中全景环境/静止对峙）**：自动分流至 16:9 影视级推拉运镜（Dolly In 空间纵深前推 / Pan 横移跟拍 / 0 额外显存秒级产出）；
   * **Tier C（剧烈打斗/武打动作迁移）**：自动路由至 Scail2 V2（动作迁移）/ MiniMax H3 / Wan 2.2 / 即梦 Seedance 视频大模型（严格受 HITL 授权管控）。
2. **FlashVSR 1.1 广播级超分收口**：
   * 针对 8GB 显存采用九宫格分块超分（仅占 1/9 显存），成片前自动将 768×432 视差切片与视频模型切片锐化拉升至 1080P 广播级！
3. **导演级运镜语言四大铁律**：
   * ① 抓主放次（全屏只留 1 个核心焦点动作，其余做微动态辅助）；
   * ② 严格区分 `Zoom In`（变焦推进，惊悚窥视）与 `Dolly In`（机位前推，空间纵深）；
   * ③ 双线思维（主体动线 + 镜头动线分开写）；
   * ④ 运镜起止点三段式（起始构图 + 运动过程含速度 + 结束定格构图）。

### 5.2 全要素五轨剪映母带工程 (Agent 9)
1. **五轨合流标准时间线**：
   * **视频轨 0**：16:9 视频切片 + 转场特效（近景切全景 `mix` 叠化 / 剧烈动作 `black_fade` 闪黑）+ 105% 关键帧防穿帮微缩放 + 打斗震动（Shake）；
   * **对白轨 1**：纯净人声台词（严格执行 **J-Cut 500ms** 先声后画，消除生硬割裂感）；
   * **音效轨 2**：动作打击音效（Foley）与场景底噪环境音；
   * **音乐轨 3**：情绪 BGM + 自动避让人声（**Audio Ducking**：台词出现时 BGM 自动压制至 20%，留白回弹至 45%）；
   * **字幕轨 4**：电影级白字黑边描边字幕条，毫秒级卡点发音。
2. **剪映官方桌面工程打包架构**：
   * 输出 `JianYing_Drafts/Projects/{Project_Name}/` 完整工程包，包含 `draft_content.json` 与 `draft_meta_info.json`，直接拖入草稿箱即开即剪，彻底消除跨设备素材丢失红叹号！

## 7. 一键全流程工业生产 SOP (Standard Operating Procedure)

## 8. 本地物理硬件实测落地结论 (8G 显存机型实机验证)

针对 8GB 显存 + 16GB 内存机型，经多轮实机压测，确立以下生产落地硬性规则：

### 8.1 视频动态：确立「混合路线 C」为主力出片管线
* **算力铁律**：Wan 14B 无法在 8GB VRAM + 16GB 物理内存运行（易被系统 OOM Kill）。
* **主力方案（混合路线 C）**：本地国漫底模出关键帧（100% 锁定人设与画风） ➜ 仅将「运镜与动态」交给云端 **Hailuo-02 (MiniMax)**。实测输出 1920×1080 / 24fps / 5.9s 物理流体与真实转身运动，彻底杜绝多镜头画风互搏。
* **离线备选（路线 B）**：单机全离线时采用 **Wan2.2 TI2V-5B (fp8 约 6GB)** 或 **LTX-Video 2B**，执行前必须触发 `/free` 卸载显存。

### 8.2 面部修复：前置分辨率提升 (1216×832) + 零安装 FaceDetailer
* **根因预防**：基础分辨率若低于 1024×576，面部仅占 ~70px；提至 **1216×832 + Hires Fix 1.5x** 后，人脸像素直达 140px+，从物理源头消灭面部溃散。
* **局部修脸**：采用 OpenCV 自动检脸 BBox ➜ `ImageCrop` 裁脸 ➜ 放大 2x ➜ KSampler (Denoise 0.35) ➜ `FeatherMask` 羽化 ➜ `ImageCompositeMasked` 贴回。

### 8.3 剪映总装：pyJianYingDraft 完整目录骨架接管
* **加密真相**：AES-256 加密为剪映保存时的行为，读取时支持完整明文骨架。
* **目录结构全要素**：必须由 `pyJianYingDraft` 完整补齐 `Resources/`、`matting/`、`Timelines/`、`draft_settings` 与 `draft_agency_config.json`，确保剪映客户端平滑解析。
* **保底兜底**：同步输出已验证的 **Premiere Pro XML (6 视频轨 + 6 音频轨 / 412 帧)** 与 OTIO，Resolve / PR 通用秒开。
