# AI 漫剧全链路生产 SOP、提示词模板库与全局排错字典（模块 04）

> **模块定位**：AI 漫剧绝不是“把小说丢给 AI 一键生成视频”，而是**“七步串行、每一步都在为下一步消灭随机性”**的系统工程。本手册整合本地 ComfyUI 免费管线与云端（即梦 Seedance 2.0 / RunningHub）商业管线，提供从剧本拆解、分镜运镜、配音剪辑到 14 套标准化提示词模板与全局排错字典的完整闭环。

## 一、 AI 漫剧七步工业化生产管线（本地 + 云端双轨 SOP）

```
[Step 1 找剧本] → [Step 2 审与转剧本] → [Step 3 角色三视图] → [Step 4 场景参考图] → [Step 5 四宫格/分镜表] → [Step 6 多参生视频] → [Step 7 单格补拍与剪辑]
     ↓                  ↓                   ↓                   ↓                    ↓                     ↓                     ↓
  爽点与反差         画面化拆解           锁死五官服装         锁空间光影色调        固定关键帧与动线       音画同出/双采防崩      IndexTTS2+剪映J-Cut
```

### 1.1 七步工序操作要点与过关验收判据

| 工序步骤 | 核心执行动作（本地 ComfyUI 轨 vs 云端即梦轨） | 交付物 | 严格过关判据（不过关绝不进下一步） |
| :--- | :--- | :--- | :--- |
| **Step 1<br>选题与找剧本** | **路径 A（改编练手）**：取小说高爽点/强反差章节（注意：商业发布严禁照搬原文、人名与完整桥段，须遵守平台授权规则）。<br>**路径 B（原创生成）**：用“灵感大师”抽兼容标签（防互斥硬扯）+ 三幕剧结构（25%铺垫 / 50%对抗 / 25%结局）分幕生成。 | 故事梗概与分场剧情 | 具备明确的情绪入口（共情/被保护）、名字或身份强反差（如“三英揍吕布”）、未说完的悬念钩子与自然融入的热梗。 |
| **Step 2<br>剧本画面化与智能体审稿** | **2a. 小说转漫剧剧本**：删掉所有心理描写与抽象概括，拆成可拍动作（如将“美婢环侍”拆为“一人喂酒、一人捶腿、身后一人捏肩”），存为本地 `.md`。<br>**2b. 智能体拆画板/分镜表**：喂入剧本，确认时长/画风/画板数，输出三幕戏剧结构、角色动机与分镜表。 | 漫剧标准剧本 + 画板/分镜拆解表 | **全流程地基**：人工复核 AI 拆出的角色动机与分镜顺序是否符合预期；AI 理解偏了必须当场用大白话纠正，否则后面全错。 |
| **Step 3<br>角色资产建立** | **本地轨**：Krea2 出纯白底正面全身图 → Qwen-Image 2.1 配合白膜合成**三视图或 2×2 四宫格**（裁掉右下角小脸）。<br>**云端轨**：即梦图片 5.0 Pro（横版 4:3，首句写“保持图像面部和发型的一致性”）或 Flux Kontext Pro。配角用白底单人图批量出。 | 主角三视图/四宫格 + 配角白底单人立绘 | 全身含鞋子完整可见、直视镜头、无动作动词、纯白底无污染；**服化道符合角色身份与当前剧情阶段**（忌盲目华丽）。 |
| **Step 4<br>场景与道具资产** | **不抠细枝末节，只锁四大方向**：① 空间结构；② 光影氛围；③ 色彩风格；④ 关键识别道具。反复出现的主场景生成 2–3 张不同机位角度参考图。 | 纯景参考图（无人物）+ 核心道具图 | 建筑体量符合剧情设定（若太满太糊则提至 2K）；多角度场景让人相信处于同一个物理空间。 |
| **Step 5<br>分镜设计与关键帧** | **路线 A（即梦四宫格关键帧法）**：1 画板 = 2×2 四宫格 = 4 个关键瞬间（约对应 **15 秒视频**；3 张分镜图 ≈ 10 秒）。生图时必须上传角色图与场景图并 **`@引用`**（且先让智能体看设定图把衣服颜色写进提示词）。<br>**路线 B（H3 多参全景站位法）**：用 Qwen-Image 2.1 将全景背景与多角色合成为“全景站位首帧图”，并在分镜提示词中加入**“人味生活细节”**（如“白说话时，双喜在旁边扒拉餐盘吃得很香，轮到他说才边嚼边讲”）。 | 2×2 四宫格分镜图 或 全景站位图 + `shot1/2/3` 提示词 | 多人同框描述**严禁写“小易/虎哥”等人名**，必须写“从左到右图一、图二、图三”+ 具体位置与动作；景别与运镜服务于剧情情绪而非单纯炫技。 |
| **Step 6<br>视频生成** | **本地轨**：MiniMax H3 双采多参流（全景站位图 + 角色资产图 + `uploadaudio` 音色参考音频，一采 `0.3MP` 验框架 → 二采 `0.8MP–1.5MP` 出片，单次 ≤10 秒）。<br>**云端轨**：即梦 Seedance 2.0 / 2.0 fast（智能多帧模式在两图中间单击填词，或首尾帧模式），全素材 `@引用`。 | 带配音/音效的视频片段（按 `D01 / D02 / D02-1备选` 命名） | 人物未换脸、远景未崩脸、比例正常；**提示词末尾必须写死“禁止出现背景音乐，不出现字幕与文字”**（防模型自带野生 BGM 污染音轨）。 |
| **Step 7<br>单格修补、配音与剪辑** | **7a. 坏镜单修**：四宫格中哪一格崩了，用画布 2×2 切分（或截图）单独抠出那一格，配单镜头提示词重跑替换，成本仅 1/4。<br>**7b. 音色统一**：用本地 **IndexTTS2**（3060 可跑）克隆角色音色，通过情感参考音频或**情感向量滑块**拉高“怒气/悲伤值”。<br>**7c. 剪映精剪**：关键帧放大遮穿帮、自定义曲线变速、J-Cut 先声后画、打斗加震动、贴音效与情绪 BGM。 | 最终导出成片（MP4） | 全片同一角色音色前后 100% 统一；配音严格卡在人物张嘴时刻；无穿帮闪烁与硬切割裂感。 |

## 二、 导演思维：让画面动起来的“动态与运镜公式”

不理解镜头语言，就只能盲从 AI 生成的平庸分镜。将以下规则直接写进提示词，可立刻摆脱“PPT 播放感”：

### 2.1 景别与情绪映射表

| 景别名称 | 画面涵盖范围 | 叙事功能与适用时机 |
| :--- | :--- | :--- |
| **远景 / 全景（Wide / Full Shot）** | 完整建筑环境 + 人物全身及相对位置 | 开场交代地点氛围、展示人物所处困境或群体对峙关系 |
| **中景（Medium Shot）** | 人物膝盖/腰部以上 | **漫剧主力景别**：用于日常对话、肢体动作交锋、多人互动（如边吃边聊） |
| **近景 / 特写（Close-up / Extreme CU）** | 胸部以上 / 仅面部或局部道具（握刀的手、颤抖的瞳孔） | **情绪爆发与反转点**：配合推镜头走进角色内心，放大微表情 |

### 2.2 视频动态与运镜四大铁律（专治画面不动或乱抖）

1. **抓主放次（所有都动 = 等于不动）**：
   - **错误写法**：“书在飞，灯在摇，桌子在跳，人在晃” → 产生满屏动态噪音，画面必崩。
   - **正确写法**：全画面只留 **1 个核心焦点动作**，其余元素做微动态辅助（例：“女孩站在海边，海浪轻轻拍打沙滩，女孩的头发和裙摆在海风中微微飘动，天空云彩缓慢移动”——每句都用 **具体动词 + 程度副词 + 方向**）。
2. **区分 `Zoom In` 与 `Dolly In`（中英并写最准）**：
   - 不要笼统写“镜头拉近”！想要瞬间惊悚/窥视感、背景压缩，写 **`变焦推进（zoom in）`**；想要带着观众走进场景、空间纵深感强，写 **`机位前推（dolly in）`**。
3. **双线思维（演员动线 + 摄像机动线分开写）**：
   - **公式**：`[主体动作与方向] + [镜头运动与跟随方式] + [画面构图保持状态]`。
   - **范例**：`一辆跑车在山路上从左向右飞驰，镜头与汽车保持同步横移跟拍（tracking shot），始终将汽车保持在画面中央。`
4. **运镜起止点三段式（首尾帧与旋转镜头必用）**：
   - **公式**：`起始构图 + 运动过程（含方向与速度变化，速度即情绪） + 结束定格构图`。
   - **范例**：`起始镜头为主角正面特写，镜头开始围绕他进行 360 度顺时针旋转，速度由慢到快，旋转过程中背景从白天的教室无缝切换到夜晚的战场，旋转一圈后最终定格在主角正面特写上，表情从天真变为坚毅。`
   - *注：希区柯克变焦（Dolly Zoom）AI 视频模型目前无法稳定直出，直接用剪映/PR 后期关键帧缩放实现。*

### 2.3 剪映后期救片五大实战技法

1. **关键帧位移遮穿帮**：定位到边缘开始崩坏或突然冒出怪异物体（如多余灯管、崩坏字牌）的那一帧 → 在「位置大小」打第一个关键帧 → 往后几帧将画面轻微放大或平移，把穿帮部位推到画框外 → 再打关键帧恢复 100%，靠自然运动感完美掩盖瑕疵。
2. **J-Cut（声音先行，画面后到）**：两镜硬切生硬时，右键下一镜「分离音频」，将**音频轨往前拖 0.5–1 秒**，让观众先听到反派开口说话的声音，画面再切过去，丝滑度立竿见影。
3. **打斗加震动与曲线变速**：打斗接触帧加「震动」特效并配合“横向模糊/闪黑”转场，既增强打击感又掩盖 AI 肢体穿模；变速禁用生硬的全局匀速，先分割片段再用**「自定义曲线变速」**（动作中段拉陡加速、定格瞬间拉平延长）。
4. **音效与 BGM 铁律**：音效遵循**“画面看到什么就贴什么”**（踩水坑、衣料摩擦、眼睛发光贴法术音）；BGM 遵循**“放大当前情绪而非好听”**（音乐库直接搜“短剧”“压迫感”）。

## 三、 标准化提示词模板库（14 套直接复制即用）

将 `<...>` 替换为你的具体内容即可投喂给 LLM 智能体（推荐 Google AI Studio 的 Gemini 2.5 Pro 开联网 Grounding，或豆包/DeepSeek）：

### T01｜小说原文 → 漫剧画面化剧本转换

```markdown
将上述小说内容转换成适合用于 AI 漫剧创作的标准拍摄剧本。
要求：
1. 彻底删除所有心理活动、抽象形容与旁白感慨，全部改写为摄像机拍得到的具体肢体动作、表情与道具交互；
2. 一句话概括的信息必须拆解为多个具体画面（例如：「身边美婢环侍」→ 拆写为「左侧侍女递上酒杯，右侧侍女蹲身捶腿，身后侍女轻捏肩膀」）；
3. 每个场景开头标注：场号 / 地点（内/外景） / 时间（日/夜） / 出场人物；
4. 每句台词前标注角色名，配合台词的微动作与神态用括号写在台词正前方。
```

### 4.1 症状 → 根因 → 工程对策速查表（Top 25 实战高频坑）

| 故障分类 | 报错或异常症状 | 底层机制/版本根因 | 一键解决对策 |
| :--- | :--- | :--- | :--- |
| **环境与节点** | 启动即崩溃或黑框闪退 | 解压根目录含**中文路径**或嵌套层级过深 | 移至磁盘浅层纯英文目录（如 `D:\ComfyUI` 或 `/opt/ComfyUI`） |
| **环境与节点** | 载入工作流后下拉框空白、跑不出图 | 模型未放入 `models/` 下正确的子文件夹，或文件夹大小写拼错 | 用启动器「模型目录」核对：`diffusion_models`、`text_encoders`、`vae`、`loras`、`model_patch` |
| **环境与节点** | 找不到千问 2.1 / Wan 2.2 等专属节点 | ComfyUI **内核版本过旧**；或误开了 **「节点 2.0」测试版** | 关掉设置里的 Node 2.0；去启动器「维护中心 → 版本更新」升级内核（保持稳定版分支） |
| **生图与参数** | 画面极度锐化、色彩炸裂、变成抽象画 | 在 2026 Turbo/加速模型上沿用了旧版高 CFG（如填了 7） | 将 **CFG 立即改回 `1`**（Turbo/Flux/加速流铁律） |
| **生图与参数** | 点执行瞬间完成，画面没有任何变化 | `seed` 被设为了 `固定（fixed）` 且未改动任何上游参数 | 将 seed 控制改为 `随机（randomize）` |
| **生图与参数** | 人物长出两个头、上下半身拼接多张脸 | 在 SD 1.5 底模上直出了超过 `768×768` 的高分辨率 | 降回 512×768 后走 Latent 放大，或直接换用 Krea2 / Z-Image / Qwen 2.1 新底模 |
| **生图与参数** | 明明写的是白猫，出来总是“小黑脸猫” | 提示词写了“纯黑背景”，发生**跨元素语义污染** | 先排查提示词中的强颜色词污染，改用纯白或中性浅色背景 |
| **生图与参数** | 海报/电商图上的英文小字全部糊成一团 | 在 Qwen-Image 2.1 上开启了加速 LoRA 或惰性缓存 | 带文字的图**严禁开加速 LoRA 与惰性缓存**，老老实实用 30–40 步慢跑，或改用 **Boogu** 模型 |
| **重绘与编辑** | 局部重绘后，涂抹区域变成一块死灰斑 | 使用了 `VAE 内部编码器（Inpaint）` 路线 B，但降噪设低了 | 路线 B 的 `denoise` **必须锁死为 `1.0`**；想用 0.3–0.5 低降噪请换路线 A（`Set Latent Noise Mask`） |
| **重绘与编辑** | Krea2 编辑节点一喂入 1K 原图就报错 | `C2 Edit` 节点硬性限制输入图像 **不超过 200 万像素** | 在 `Load Image` 后必须前置 **`调整图像大小（缩放至最长边 = 1600）`** |
| **重绘与编辑** | Krea2 编辑出图与原图毫无关系（且不报错） | `C2 Edit` 节点的 4 个输入口**漏连了参考图那根线** | 逐一核对 `model`、`latent`、`clip`、`image` 四根线是否全部连齐 |
| **资产与一致** | 转三视图时角色长发消失、或没有下半身鞋子 | 原图长发与深色背景同色；或原图只给了半身照/带低头动作 | 角色基底图必须是：**纯白底 + 正面全身含鞋 + 直视镜头 + 删掉所有动作动词** |
| **资产与一致** | 上传了角色白袍设定图，分镜里衣服却变黑袍 | 提示词里残留了“身穿黑袍”文字，模型**只参考了脸、按文字画了衣服** | 先把角色设定图传给智能体，让它在生成的提示词里明确写出“参考图一，身穿白色长袍” |
| **视频生成** | MiniMax H3 / LTX 2.3 启动报错无法运行 | 漏装或漏连了 **`audio VAE`**；或删音频 VAE 时没删音频预览节点 | 补齐 `video VAE + audio VAE` 双加载器；若跑静音需将下游音频预览节点一并删除 |
| **视频生成** | H3 视频里人物一走到中远景，脸就严重崩坏 | 低像素单采直出导致远景面部潜空间网格不足 | 改用 **H3 双采多参流**（一采 0.3MP → 二采放大至 0.8MP），并将二采降噪步数提至 3–4 步 |
| **视频生成** | H3 双采放大后，人物说话声音变得怪异畸变 | 潜空间放大节点把音频 Latent 也一起放大了 | 放大前必须加 **`H3 AV Latent Separate`** 拆开音视频，只放大视频 Latent 后再 Merge 合并 |
| **视频生成** | Wan 2.2 图生视频出来满屏彩色马赛克杂点 | 高噪（High）与低噪（Low）两个 4 步加速 LoRA **装反了** | 严格核对第一个采样器挂 High LoRA（0–2步），第二个采样器挂 Low LoRA（2–4步） |
| **视频生成** | 首尾帧生成的视频画面剧烈抽搐或抽象变形 | 首帧图与尾帧图尺寸比例不一致；或 Wan 2.2 首尾帧用了 FP8 模型 | 用 `图像缩放（1.5MP 或按宽高比限1024）` 强制统一两图宽高；Wan 2.2 首尾帧换回 **BF16/FP16** 底模 |
| **视频生成** | 生成的视频自带诡异背景音乐，后期去不掉 | 多模态音画模型默认会自动脑补配乐 | 在视频提示词末尾强制加上一句：**“禁止出现背景音乐，不出现字幕与文字”** |
| **专项与后期** | InfiniteTalk 数字人口型乱动、头部鬼畜摇晃 | 输入的音频里混有 BGM 伴奏旋律 | 在音频进入 `wav2vec` 之前，必须先接 **`人声分离节点`** 提取纯人声干音 |
| **专项与后期** | Scail2 动作迁移后，人物周围有一圈刺眼白边 | 喂入的纯白底角色参考图未做抠图去背处理 | 开启流内的 `图像背景移除` 节点，或断开两个 Mask 输入口仅做纯动作迁移 |
