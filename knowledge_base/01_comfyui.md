# ComfyUI 底层原理与核心工作流拆解手册（模块 01）

> **模块定位**：任何花哨复杂的千节点工作流，拆到底层都是**“文生图五件套”在某个数据节点上的替换、串联或分块**。本手册帮你建立组件化拆解思维，彻底搞懂 2026 新旧两代工作流骨架、采样器参数真相、局部重绘双路线与 ControlNet 铁律。

## 一、 核心心智模型：从“五件套”到 2026 分离式骨架

### 1.1 万流之源：经典文生图五件套（六节点地基）

无论模型如何迭代，ComfyUI 的数据流永远遵循 **“模型加载 → 提示词编码 → 潜空间采样去噪 → VAE 解码输出”** 四段式结构：

```
[1. 模型加载器] ──┬── MODEL（大脑/画师：决定画风与知识边界） ──────────┐
                  ├── CLIP （翻译官：人话 → 向量）─→ [2. CLIP文本编码×2] ─┼─→ [3. K采样器] ─→ [5. VAE解码] ─→ [6. 保存/预览]
                  └── VAE  （转换插头：潜空间 ⇄ 像素空间）──────────────┼──────┘               ↑
                                                                        │                      │
                                             [4. 空Latent图像（白画布：定义宽高与批次）] ───────┘
```

- **为什么要在“潜空间（Latent Space）”里画画？**
  像素图像直接计算量极大；VAE 编码器先把像素图压缩进尺寸小得多的“看不见的潜空间”，UNet 大模型在潜空间里经过 $N$ 步迭代把噪声一层层剥离（去噪），最后再由 VAE 解码器还原成肉眼可见的像素图。
- **重要铁律：减少潜空间与像素空间的无谓往返**
  每经过一次 `Latent → VAE 解码（变图像）→ VAE 编码（变回 Latent）`，画面就会产生肉眼可见的像素损耗（可通过 `图像对比` 节点的 `diff` 模式观测到丢失的像素点）。因此，**两级采样之间能用 `Latent 按系数缩放` 直连，就绝不要先解码成图像再缩放编码**。
- **ComfyUI 相比 WebUI 的核心优势**：确定性极高。只要 **随机种子（Seed）+ 参数 + 模型链路** 完全一致，无论重跑多少次，输出像素 100% 严丝合缝，这使得“固定种子做单变量对照实验”成为最可靠的调参手段。

### 1.2 2026 新世代工作流的四大结构变异

拿到 2026 年的新工作流（如 Z-Image-Turbo、Krea2、Qwen-Image 2.1、MiniMax H3、LTX 2.3）时，你会发现找不到传统的 `Checkpoint 加载器` 或单一 `K 采样器`。它们发生了以下 4 处标准变异：

| 变异部位 | 传统形态（SD 1.5 / SDXL） | 2026 新世代形态 | 为什么要这样改？（工程原因） |
| :--- | :--- | :--- | :--- |
| **1. 模型加载区** | 单个 `Checkpoint 加载器` | 拆分为 **`UNET 加载器` + `CLIP 加载器` + `VAE 加载器`**（视频流含 **video VAE + audio VAE**） | 2026 大模型体量巨大（动辄 12G–40G），将主干网络（UNet/DiT）、多模态文本编码器（Qwen3-VL / Gemma-3 / umt5）与编解码器解耦，方便单独量化（FP8/GGUF）和跨模型复用 |
| **2. 负面条件区** | 红色 `CLIP 文本编码器` 填满负面词 | 替换为 **`Conditioning Zero Out（条件零化）`** 节点，或合并进专属单节点 | Turbo 与流匹配（Flow Matching）架构底模质量极高，无需负面词对冲；但采样器端口不能悬空，故将正面条件清零后接入负面口占位 |
| **3. 采样器区** | 单个集成式 `K 采样器（KSampler）` | 拆分为 **采样五件套**：`随机噪波` + `基本引导器` + `基本调度器` + `K采样器选择` + `自定义采样器`（或外挂 `自定义 Sigma` / `分离 Sigma`） | 把种子、引导（Guider）、去噪节奏（Scheduler/Sigma 曲线）和算法彻底拆开，支持两阶段采样（`分离 Sigma` 分配一采/二采步数）和专属调度器（如 `flux2 scheduler`） |
| **4. 连线组织区** | 满屏跨越画布的长连线或 `转接点（Reroute）` | 大量使用 **`Set 节点`（存变量）与 `Get 节点`（取变量）** + `节点组开关（Fast Groups Muter/Bypasser）` | 纯粹为了**画布无线化整洁**，功能上与直接连线毫无区别。扩展参考图（如 `image 5` → `image 6`）时只需复制 `Set/Get` 并修改右键属性中的 `match title` 索引 |

## 二、 K 采样器参数真相与跨代际调参表

不要盲目迷信网传的“玄学参数”，每个旋钮都有明确的数学与工程边界：

| 参数名称 | 底层物理含义 | 传统模型安全区（SD 1.5 / SDXL） | 2026 新模型安全区（Turbo / DiT） | 高频踩坑与排错指南 |
| :--- | :--- | :--- | :--- | :--- |
| **seed（随机种）** | 初始噪声图的“身份证号” | 抽卡设 `-1`（随机）；调参对比设 `固定（fixed）` | 同左（若换了采样器算法，同 seed 也会画出完全不同的人） | 点运行后画面一动不动、瞬间结束？**先查是不是把 seed 锁死在固定值了** |
| **steps（步数）** | 去噪迭代的画笔次数 | **20–25 步**（超过 50 步纯属浪费显存且画面易崩） | **4–12 步**（Boogu 4步、Z-Image 8–9步、Krea2 8–10步、H3 12步）；**唯独 Qwen-Image 2.1 不开加速需 25–40 步** | 原生 20–30 步的大模型，只有挂载了 `lightx2v` / `EMA` 等蒸馏加速 LoRA 后才能降到 4–12 步，裸降步数必糊 |
| **CFG（引导系数）** | 强迫画师听从提示词的力度 | SD 1.5: **6.5–8**；SDXL: **5–6** | **严格设为 1**（所有 Turbo / Flux / 加速视频流通用） | **头号铁律：模型越强，CFG 必须越低**。在 CFG=1 的模型上填 7，画面会严重过拟合（死黑死白、锐化刺眼、纹理炸裂） |
| **sampler（采样器）** | 每一步去噪的数学路径算法 | 写实首选 `DPM++ 2M`；次选 `DDPM`；动漫可用 `Euler / Euler a` | Z-Image: `res_multistep`；Wan 2.2 I2V: `uni_pc`；Small Mist: `Euler a`；Boogu/Wan T2V **固定不可乱改** | 2026 蒸馏模型对采样器高度敏感，乱改官方指定采样器会导致直接报错或满屏噪点 |
| **scheduler（调度器）** | 每一步削减多少比例的噪声 | 通用首选 `Karras` | Wan 系常用 `simple`；Small Mist 用 `normal`；Qwen 2509 用 `beta`；Flux2 用专属 `flux2 scheduler` | 采样器与调度器必须成对匹配，切换底模后若画面浮空、失重，优先排查调度器是否选错 |
| **denoise（降噪/重绘幅度）** | 先把原图涂掉多少比例的像素再重画 | 文生图锁死 `1.0`；图生图 `0.2–0.7` | 双采二阶段通常由 `分离 Sigma`（如 12 步拆 8+4）或 `0.2–0.3` 低降噪控制 | 见下表《降噪阈值黄金标尺》 |

### 降噪幅度（Denoise）黄金标尺（图生图 / 高清重绘核心开关）

| Denoise 数值 | 画面表现结果 | 典型工程用途 |
| :--- | :--- | :--- |
| **0.00** | 原图 100% 原样输出，一丁点都不改（因为没加任何噪声） | 测试工作流链路是否连通、验证单纯 VAE 编解码损耗 |
| **0.20 – 0.30** | 严丝合缝保留原图五官、表情与构图，仅补充高频皮肤纹理与发丝细节 | **两阶段高清放大重绘**（0.2 最保守稳妥；上到 0.3 五官微表情可能开始微变） |
| **0.45 – 0.50** | 保留人物主体姿态与五官骨架，但材质光影发生显著改变 | **动漫/老照片真人写实化微调**（实测 0.45 比 0.5 更能保住原图神态） |
| **0.65 – 0.75** | 仅保留大致构图轮廓与色块分布，AI 大幅注入自身创意 | **跨画风转绘、二次元转 3D、艺术风格重构** |
| **1.00** | 把原图彻底涂满噪声重画，输出内容与原图毫无关系（仅继承原图宽高尺寸） | **文生图模式**，以及 **`VAE 内部编码器（Inpaint）` 局部重绘模式** |

## 三、 局部重绘（Inpainting）的 A / B 两条路线与遮罩工程

很多人做局部重绘时遇到“重绘区变成一块灰斑”或“死活改不动颜色”，根源在于混淆了 ComfyUI 中底层逻辑完全不同的两条重绘路线：

### 3.1 局部重绘 A / B 路线对比表

| 对比维度 | 路线 A：图生图掩码路线（微调首选） | 路线 B：文生图内补路线（大改首选） | 终极组合拳（既要自由度又要锁结构） |
| :--- | :--- | :--- | :--- |
| **核心节点组合** | `VAE 编码` + `设置潜空间噪波掩码（Set Latent Noise Mask）` | `VAE 内部编码器（VAE Encode for Inpainting）` | **路线 B（降噪=1.0）+ `lineart ControlNet`** |
| **底层等价逻辑** | **局部图生图**（在原图潜空间像素基础上加噪） | **局部文生图**（直接把遮罩区域挖空换上纯白新画布） | 用路线 B 释放大模型全部创造力，同时用 Lineart 锁死原图线条与边缘 |
| **降噪（Denoise）要求** | **可低可高（推荐 0.3–0.65）** | **必须锁死为 1.0！** | 锁死 **1.0** |
| **核心优缺点** | 边缘过渡极自然，参考原图形状与光影；但降噪低时改不动大结构，降噪高时边缘易糊 | 自由度极大，可凭空生成全新物体或换背景；但**一旦降噪低于 1.0，遮罩区未降完的底噪就会变成一团灰块** | 彻底解决路线 B 边缘不贴合与结构跑偏问题（若边缘仍糊，说明手涂遮罩范围过大，收紧遮罩即可） |
| **适用场景** | 换发色、改衣服材质、微调五官表情 | 白底产品图换真实大场景、大面积更换服装款式、无中生有添加道具 | 复杂角色精修、商业级换背景与局部重构 |

### 3.2 遮罩（Mask）工程的三个实战铁律

1. **白改黑不改**：在 ComfyUI 的遮罩逻辑里，**白色代表“要被重绘修改的区域”，黑色代表“锁死保护不动的区域”**（注意：画板上手涂显示为黑色半透明笔迹，生成出的遮罩通道里实际是白色）。
2. **极小区域改不动怎么办？** 当你要重绘的区域只有几十个像素（例如远景人物的瞳孔改红眼），即便 denoise 给到 0.6 也毫无反应——因为潜空间压缩后该区域只剩几个像素点。**解法**：要么先将画布放大，要么切路线 B 将 denoise 直接拉到 1.0。
3. **告别手涂：用 `SAM（Segment Anything）` 实现像素级自动抠图**：
   - **图像语义分割**：使用 `SAM Model Loader`（推荐选 2.56GB 最强版权重）+ `Grounding DINO`，直接输入英文单词（如 `hair`、`eyes`、`shoes`、`person`），自动输出精准边缘遮罩。
   - **白底产品换场景必做“遮罩反转”**：SAM 默认把识别到的“产品”标为白色（前景），如果直接连重绘，会把产品重画而保留白底！必须接一个 **`遮罩反转（Invert Mask）`** 节点，把背景变成白色，才能实现“保护产品、重绘背景”。
   - **视频人物自动跟踪（2026 新增）**：在动作迁移（`Scail2`）工作流中，使用最新的 **`SAM3`**（放入 `models/checkpoints`）输入 `person` 即可对整段视频做逐帧人物遮罩跟踪，并用红/蓝双色区分视频人物与参考图人物。

## 四、 ControlNet 四大金刚与“同族配套”铁律

ControlNet 的本质是在采样器的**“正/负条件（Conditioning）输入端”**加装一道空间几何护栏。

### 4.1 预处理器与模型选型速查表

统一推荐使用 **`Apply ControlNet (Advanced) / ControlNet 应用（旧版高级）`** 节点（自带强度与起止步数旋钮）：

| 控制类型 | 推荐预处理器（ControlNet Aux） | 对应 ControlNet 模型 | 核心控制维度与视觉特征 | 黄金实战场景 |
| :--- | :--- | :--- | :--- | :--- |
| **1. 线条（Lineart）** | `lineart`（写实） / `lineart_anime`（动漫） | `control_v11p_sd15_lineart` 或 SDXL Lineart | 提取精细黑白线稿，1:1 锁死边缘与五官纹理细节 | **线稿自动上色**（若输入本身就是黑白线稿，需先接 `图像反转` 变成黑底白线，直接跳过预处理器）、**老照片修复保真首选** |
| **2. 软边缘（SoftEdge）** | `HED 模糊线预处理器` | `control_v11p_sd15_softedge` | 仅保留柔和的主体大轮廓，抹除内部细碎纹理 | **艺术风格转绘、二次创作**（既保住原图构图，又给新模型留出充足的笔触发挥空间） |
| **3. 深度（Depth）** | **`Zoe 深度预处理器`**（或 `Depth Anything`，无脑首选） | `control_v11f1p_sd15_depth` 或 SDXL Depth | 生成黑白景深图（**越白代表离镜头越近，越黑代表越远**），锁死三维空间透视 | **白底产品图换真实场景锁透视**（防止产品像悬浮在半空）、室内设计改装修风格 |
| **4. 姿态（OpenPose）** | `openpose 预处理器` | `control_v11p_sd15_openpose` | 提取彩色火柴人骨骼、手部关节与面部朝向点 | **角色动作复刻**、**约束 SD Upscale 分块放大**（防止分块重绘在角落长出多余的手或人脸） |

### 4.2 ControlNet 三条保命铁律

1. **同族同代严格配套**：`预处理器类型 ↔ ControlNet 模型类型 ↔ 底模代际（SD1.5 / SDXL / Flux / Qwen-Image 2.1）` 三者必须严格对齐！
   - 反例：用 SD1.5 的麦橘 V7 底模去挂 SDXL 的 ControlNet，或者用 Canny 预处理器去连 Depth 模型，结果必然是满屏彩色噪点或完全不生效。
   - **2026 新模型特例**：`Z-Image-Turbo` 与 `Qwen-Image` 系列需使用专属的 `Qwen-Image ControlNet` 节点，并以 **`model_patch`** 方式加载（模型必须放在 `ComfyUI/models/model_patch/` 目录下，且必须选 **2.1 版 UNet**，选低阶版效果暴跌）。
2. **善用“结束时间（end_percent = 0.90）”消除怪异伪影**：
   - 如果把 `strength（强度）` 设为 1.0 且 `end_percent` 设为 1.0，模型从第一笔到最后一笔都被死死绑住，极易出现肢体僵硬或边缘多出莫名其妙的线条。
   - **最佳实践**：将 **强度设为 `0.75–0.90`**，并将 **结束时间设为 `0.90`**——让 ControlNet 管住前 90% 的构图与骨架，最后 10% 的收尾去噪交还给大模型自由柔化，画面立刻自然。
3. **多重 ControlNet 串联法**：
   - 按住 `Alt` 拖动复制第二个 `Apply ControlNet` 节点，将第一个节点的 `正面/负面条件输出` 直接连入第二个节点的 `正面/负面条件输入`，最后一个节点再连入 K 采样器。
   - **经典三控公式（老照片修复/极致还原）**：`Lineart（保五官细节）+ Zoe Depth（保前后空间）+ OpenPose（保骨骼朝向）` 三路串联，再配合 `Florence` 自动反推提示词与 `ReActor` 面部换脸精修，可实现全自动一键无损翻新。

## 五、 高频画布操作与效率快捷键表

| 目标操作 | 快捷键 / 标准动作 | 工程实用技巧 |
| :--- | :--- | :--- |
| **搜索并添加节点** | 画布空白处 **双击左键** | 记不住全名时输关键词（如 `seed`、`upscale`、`zero`） |
| **临时禁用/跳过某节点（Bypass）** | 选中节点或框选组 → **`Ctrl + B`** | 节点变紫色代表数据直接穿透跳过，连线无需拆断（再按一次恢复） |
| **完全静音/关闭某节点（Mute）** | 选中节点 → **`Ctrl + M`** | 节点彻底不执行，常用于关闭备选分支（如单图/双图编辑二选一） |
| **快速复制节点（保留参数）** | 按住 **`Alt` + 鼠标左键拖动** | 串联多个 LoRA 或多重 ControlNet 时最快 |
| **整束连线一键搬家** | 按住 **`Shift` + 左键点击接口并拖向新节点** | 替换采样器或编码器时，不用一根根拔插连线 |
| **多节点框选与批量移动** | 按住 **`Ctrl` + 左键框选** → 按住 **`Shift` 拖动** | 整理凌乱工作流必备 |
| **新建分组框（Group）** | 框选多个节点 → **`Ctrl + G`** | 右键分组框可改标题、颜色；配合 `Fast Groups Muter` 即可做成一键总开关 |
| **把固定数值变成可连线输入口** | 右键节点 → **「转换 [参数名] 为输入」** | 旧版 ComfyUI 常用；新版多数参数左侧已自带圆点，直接拉线即可 |
| **长距离防蜘蛛网连线** | 拖出连线松手 → 选 **`Reroute（转接点）`**，或用 **`Set / Get`** | 跨半个屏幕的线一律用 `Set/Get` 隐藏，双击 `Get` 节点可瞬间定位到源头 `Set` |
| **快速定位报错元凶** | 观察画布上带 **粉红色/红色高亮边框** 的节点 | 90% 是数据类型连错（如把浮点数连进整数 seed）或模型下拉框为空 |
