### 1.2 Krea2 单采与双采（4K→6K）工作流要点

1. **单采标准流（角色/场景设计主力）**：
   - 模型区串联 **5 个 LoRA 加载器**（主模型是画师，LoRA 是给画师的风格参考册；暂不用的 LoRA 选中按 `Ctrl+B` 旁路跳过，无需拆线）。
   - 分辨率选择器：`百万像素（Megapixels）` 填 **`2`** 对应约 1K（1920×1088）；虽然支持填 `4` 或 `8` 直出 4K，但耗时成倍增加，**漫剧资产用 1K–2K 完全足够**。
2. **双采高清放大流（4K → 6K 原理）**：
   - Krea2 单采上限为 4K（800 万像素）。若需 6K 巨幅图，采用**两个 K 采样器串联**：一采设 800 万像素跑半程去噪（不跑完）→ 接 `缩放 Latent（Latent Upscale）` 放大 `1.5 倍` → 送入二采跑完剩余步数。
   - **实战价值**：日常生图极少需要 6K，但这套**“一采定框架 + 潜空间放大 + 二采补细节”**的双采机制，是后续视频生成（MiniMax H3 / LTX 2.3）省显存与防崩脸的核心基石。
3. **三模型同屏横向对比技巧（`Prompt Line` 批量测试）**：
   - 将同一个 `Empty Latent` 同时连入 3 个不同模型的 `KSampler`，前端接 `Prompt Line` 节点可一次性输入多段提示词批量跑图对比。
   - **必避大坑**：`Prompt Line` 里**段与段之间严禁留空行**！一旦出现空行，节点会静默重复生成上一段提示词。

## 二、 2026 指令级图像编辑模型选型与实操

### 2.2 Qwen-Image 2.1 编辑流专属排错技巧

1. **找不到千问节点？** 启动器 → 维护中心 → 版本更新，升级 ComfyUI 内核至最新版。
2. **如何把 5 图输入扩展到 6–10 图？**
   - 框选第 5 路 `加载图像 + Set image 5` → 复制一份 → 将 `Set` 节点改为 `image 6`，並在文本编码区复制一个 `Get image 6`；
   - 框选新模块按 `Ctrl+G` 打组命名为 `image 6` → 复制顶部的快捷开关节点 → 右键打开属性面板，将 **`match title` 中的 `5` 改为 `6`**，开关即可精准控制第 6 张图。
3. **画面显得“很脏”、细节堆叠过度怎么办？**
   - **`千问缓存节点`**：缓解显存与内存压力且几乎不掉速，**日常无脑常开**。
   - **`惰性缓存节点`**：平时保持关闭（开启会削减细节）；**仅当出图画面显得“很脏”、高频噪点细节堆砌过多时开启**，可立刻让画面干净清爽。
4. **双图换装时“画风被带偏（风格迁移）”怎么办？**
   - 当图 1（二次元角色）与图 2（真人实拍衣服）画风不一致时，直接换装会把角色也变成真人风。
   - **解法**：最省事的方法是**确保上传的两张参考图属于同一绘画风格**；或者在编辑提示词中用强权重明确锁死目标画风。

## 三、 漫剧角色、场景与道具资产库建立 SOP（2026 标准版）

在 AI 漫剧（尤其是 MiniMax H3 / Seedance 2.0 多镜头生成）中，**没有稳定的资产图，角色必定一镜换一张脸**。

### 3.1 角色设定基底图的“四要四不要”铁律

在生成第一张角色单人图时，必须遵守以下规范，否则后续转三视图必丢特征：

| 规范维度 | 错误做法（必踩坑） | 2026 标准做法（过关判据） | 工程原因 |
| :--- | :--- | :--- | :--- |
| **1. 背景颜色** | 复杂场景背景，或深色长发配暗黑背景 | **纯白色背景（White Background）**，或与角色发色/服装主色高对比度的极简纯色底 | 头发与背景同色会导致模型无法识别发丝边界（转四视图时“长发直接消失”）；白底在后续多人分镜合成时提示词零污染、抽卡次数最少 |
| **2. 景别构图** | 半身照、坐姿照、大俯视/仰视透视照 | **全身正面站立构图（Full-body Front View）**，从头顶到鞋子完整露出 | 半身图做视频时下半身与鞋子全靠 AI 盲猜；俯视构图会拉宽脸型、扭曲头身比，导致后续全片比例失调 |
| **3. 眼神与姿态** | 写“走路低头含胸”“侧身回眸”等动词 | **删掉所有动作动词！** 只写静态外貌/身材/服装，且角色必须**直视镜头** | 角色图一旦带动作给出侧脸，生成视频头部摆正时会出现五官信息差；直视镜头才能给模型提供最清晰的瞳孔与眼型参考 |
| **4. 气质与服化道** | 盲目追求“极致华丽”（把女婢画成公主、把创业期掌柜画成富态员外） | **符合角色身份、所处环境与当前剧情阶段**，并加入 **1–2 个独特视觉锚点**（如特定发夹、耳环、刀疤、眼镜） | 独特小配饰是跨镜头锁死角色身份的最强视觉锚点；服化道脱离剧情逻辑会让观众瞬间出戏 |

### 3.2 角色多视图版式演进：为什么废弃“横版四视图”，改用“三视图 / 四宫格”？

1. **已废弃版式：传统横版四视图（正面 + 正侧 + 背面 + 半身横排）**
   - **废弃原因**：在一张横图里塞入四个全身像，**每个人的脸部（尤其是侧脸）分配到的像素面积太小**；而视频模型参考资产图的核心目的就是看清“正脸与侧脸五官”，模型极少因为缺少 90° 纯侧面全身图而崩坏，却会因为脸部像素太糊而频繁崩脸。
2. **2026 主力版式 A：新版横版 4:3 三视图 + 表情特写**
   - 包含正面全身、背面全身及 2–3 个大比例面部表情特写（平静/微笑/愤怒），手动锁定 **4:3 横版**。
3. **2026 主力版式 B：2×2 四宫格角色参考图（侧脸防崩神器）**
   - 当发现视频模型在镜头摇移时**角色侧脸不好看或崩坏**，立刻改用四宫格版式（左上是正面半身大图、右上是 45°/90° 侧脸大图、左下是背面/细节、右下是全身像）。
   - **关键实操细节**：四宫格右下角的全身像里，**正面小脸必须手动裁掉或遮挡**！目的是防止视频模型去参考那个低像素小脸，强迫它只参考左上和右上的高清大脸。

### 3.3 2026 角色资产构建“跨模型组合拳”（Krea2 + Qwen-Image 2.1）

如果做二次元/国风/奇幻漫剧，千万不要直接用 Krea2 生出三视图（Krea2 不挂 LoRA 排不出标准三视图，挂自带旧版四视图 LoRA 又是淘汰版式）。**最稳的工业级流水线如下**：

1. **Step 1（Krea2 定风格出单人全身图）**：
   - 打开 **Krea2 单采文生图工作流**，挂载对应画风 LoRA，输入详细外貌服装提示词，生成 1 张满意的 **纯白底、正面全身、直视镜头** 的角色立绘图。
2. **Step 2（Qwen-Image 2.1 + 白膜图合成标准资产图）**：
   - 切换到 **Qwen-Image 2.1 图像编辑工作流**；
   - `图 1（image1）` 上传刚生成的 Krea2 角色全身图；`图 2（image2）` 上传一张 **标准三视图/四宫格白膜排版参考图**；
   - 调用配套提示词 Skill 生成转换指令（要求保持图 1 角色面部、发型、服装与画风完全一致，按图 2 的排版生成正/侧/背视图），步数设 **25–30 步**（不开加速 LoRA），一键产出高清标准角色资产图。
3. **Step 3（配角降本增效策略）**：
   - 出场仅一两个镜头的次要配角**不做三视图**！直接用一句话批量模板：“总计设计四个角色，分别生成四张图，每张纯白背景、全身正面构图、画风一致”，一次出齐四张白底单人图即可。

### 3.4 1407 套服装 + 1439 套姿态图库一键换装换姿工作流

针对短剧中高频的“同一角色换不同季节衣服、摆特定动作”需求，无需手写复杂姿势提示词，直接使用开源 **换装换姿态图库节点**（理论组合超 200 万种）：

1. **图库构成**：服装图库含 **1407 套**（按春夏秋冬、常服/礼服等分类）；姿态图库含 **1439 套**（按正面/俯视/仰视/侧面及单人/双人分类）。
2. **开关逻辑**：工作流内“服装替换”与“姿态替换”为两个独立开关；若同时开启，系统默认执行 **“先换装，再换姿态”**，像素设 **200 万（2MP）** 即可。
3. **必避大坑（版型与动作冲突）**：
   - **现象**：明明选了“大跨步/劈叉”姿势，生成的角色双腿却张不开。
   - **根因**：所选服装款式限制了物理动作（例如给角色穿了紧身窄腿裤或紧身长裙，模型认为该版型做不出大开度动作）。
   - **铁律**：**先定服装版型，再选匹配姿态**；大动作镜头务必搭配宽松裤装或短裙。

## 四、 经典商业修图与高清修复 SOP

### 4.1 路线图：低清图 → 商业级高清大图（三级放大体系）

| 路线级别 | 工作流节点链路 | 适用场景与画质表现 |
| :--- | :--- | :--- |
| **L1：纯模型超分（快糙猛）** | `加载图像 → 图像通过模型放大（4x-UltraSharp 写实 / 4x-Anime 6B 动漫）→ 保存` | 1 秒出图，尺寸变大 4 倍、边缘变锐，但**不会新增任何皮肤毛孔或发丝细节**，画面偏涂抹感 |
| **L2：模型预放大 + 低降噪潜空间重绘（成品主力）** | `4x 模型放大 → 限制图像区域（限长边 1024–1536 防爆显存）→ VAE 编码 → K采样器（denoise 0.20–0.25, DDPM + Karras）→ VAE 解码` | **性价比最高**：既获得超分清晰度，又通过 0.2 降噪让大模型补齐真实的皮肤纹理与发丝光泽，且五官 100% 不变 |
| **L3：L2 + SD Upscale 分块重绘（2000px+ 海报级）** | 在 L2 后面再接 `SD Upscale 节点（挂 4x 模型，denoise 0.2–0.3）` + **前置串联 `OpenPose / Depth ControlNet`** | 把大图切成小瓦片逐块重绘再拼接；**必须挂 ControlNet 锁死全局结构**，否则分块处极易长出多余的手指或怪异花纹 |

### 4.2 两条高频商业自动化流水线

1. **电商白底产品图 → 真实光影场景合成**：
